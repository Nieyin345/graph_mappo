# QKD-SAGIN：天气驱动量子密钥生成与网络调度

本仓库是面向卫星（SAT）—高空平台（HAP）—地面站（GS）量子密钥分发网络的**科研仿真与调度实验项目**。主要环节为：轨道与链路几何、动态天气驱动的 FSO-QKD 信道、诱骗态 BB84 有限密钥块、共享密钥库存/请求服务，以及启发式和强化学习调度。

> **项目入口更新：2026-10-09。** 不要把早期 README、实验日志或旧模型审查中的训练数值直接当作当前实验成绩。当前性能必须以具体数据集、配置、checkpoint、评测协议及日志为准。

## 项目目录

```text
qkd_rl/               核心业务、图环境、调度策略、模型与训练算法
tools/channel_v7/     当前 v7.5 光学信道与天气/云状态计算
tools/channel_v2/     兼容、气象读取与旧信道基础模块；不能因版本名较旧就删除
tools/dataset_v2/     生产数据集生成、有限密钥计算及 H5 接口
scripts/              训练、评估、诊断、基线与论文绘图的程序入口
configs/              场景与各实验臂配置；历史配置可能被复现实验引用
tests/                单元与集成测试
docs/                 当前规范、实验证据、论文及历史归档
deployment/           服务器部署、同步与运行入口
dataset/, weather/    模型输入、气象和历史/生产数据
outputs/              本地训练产物、图表、指标、checkpoint 等
server_results*/      服务器同步的旧/新运行记录
reference/            第三方研究参考代码
.tmp/, .archive/      临时分析与历史保存，不是当前系统的规范来源
```

## 信道模型的当前结论

主线采用 v7.5 工程信道模型：1550 nm、空间/空地四类链路、真实轨道几何、分层天气输入接口、云遮挡门控、有限密钥块聚合等。当前受控合成天气下的趋势及速率量级检查已完成；**真实 ERA5/CAMS 天气标定、全链路物理精度以及网络端到端模型验证不能据此宣称完成**。

## 小规模测试

在具备项目 Python 依赖的环境中，从仓库根目录运行：

```powershell
python -m pytest -q tests/test_channel_v75_input_guards.py tests/test_channel_v7.py tests/test_channel_v7_fixes.py tests/test_channel_v75_regressions.py
```

这组是信道局部回归，不会生成完整年度 H5。生产数据集生成、正式训练或评测前应先读对应脚本的帮助与 `configs/README.md`，并固定输出目录，避免覆盖已有实验结果。

## 文件整理原则

- `docs/` 根目录优先保留现行主规范、主要验证报告和可追溯实验记录，过期审查/交接稿进 `docs/归档/`。
- 旧版物理计算仍可能通过 `tools/channel_v2/` 被生产 v7 模块复用，**不能按目录名直接清除**。
- `.tmp/`、`outputs/`、`configs/`、`server_results*/` 包含大量实验依赖或复现材料；此次仅清点，**没有批量删除或更名**。
