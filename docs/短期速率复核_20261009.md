## 发现并修正的问题

### 1. 无效物理样本可能使验证脚本崩溃

`released_keys` 原来用 `np.where(valid, key_length_gains(...), np.nan)` 处理无效块。由于 Python 会先计算函数参数，含 NaN 的块仍会传入有限密钥函数；当前函数的严格输入校验会抛出异常。现在仅对有效块调用有限密钥函数，无效块保留 NaN。

新增测试确认：一个保留窗口包含无效样本时，该块标为 NaN，下一块可正常恢复；完全被云门控排除的无效窗口不污染保留计数。原六场景未出现该类样本，所以此次修复不改变其数值。

### 2. 块长判据写死了 60 s

原判据 `duration // 60` 仅适用于当前 60 s 时隙。现在使用 `fk.slot_s`，并拒绝非正数或不是时隙长度整数倍的块长。原实验用 60 s 时隙，因此数据不受影响。

### 3. 检查失败仍返回成功退出码

汇总脚本原来只输出失败列表，没有非零退出码。现在只要任一一致性检查失败就返回失败，避免被自动流程误判为通过。

已用独立临时副本故意制造块长单调性错误验证：程序确实返回退出码 1；原数据未修改。结果保存于 `failure_exit_test.json`。

### 4. 输出没有记录源码身份

旧 `metadata.json` 有硬件、协议和场景参数，但没有源码哈希，不能仅凭这些参数证明数据对应当前代码。新增结果记录生成脚本、v7 光学模型、数据计算、底层模型、构建器与有限密钥实现的 SHA-256。用新快照重跑后，上述汇总数据完全一致。

## 仍须保留的解释边界

1. 本轮仍是合成天气；没有完成真实 ERA5/CAMS 输入的新规范验证，也没有用短期观测标定模型。
2. 文献对照属于跨设备数量级核对；当前结果不是与墨子号或 HAP 论文的同参数复现。
3. 增强湍流场景的星地可见子步约 13.65% 在弱起伏域外，必须单独报告。
4. 星间长距离的正渐近代理率不代表能在 60 s/300 s 内释放有限密钥。
5. 全链路独立接触产能不等于受终端匹配、路由和库存约束后的网络吞吐量。
