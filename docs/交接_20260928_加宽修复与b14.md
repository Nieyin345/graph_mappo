- 边特征行 `[物理块 | 需求块]`；BC `v8/screen_bc_noatt`：物理 28 + 需求 16；开 recency：物理 29 + 需求 16。

  布局来自 checkpoint 内的 `config.features.dims.{physical,demand}_edge_dim_resolved`。state_dict 与 Adam 矩同规则。

- `tests/test_checkpoint_edge_layout.py` 3 项；变异（插入→追加）使前两项失败。
