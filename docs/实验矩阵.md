## 0. 读表须知（**三条，缺一不可**）

1. **窗口是结论的一半**。本表全部用**预注册窗口 u25/u30 的均值**
   （`scripts/diag/paired_verdict.py` 的默认），与 v1/v2/pm_decode/gae90/cmax/
   demandedge 的预注册一致。**换窗口结论会变**（`cmax` 就是例子，见 §3）。
2. **"测不出"必须带可检测效应**。同一个词，一族可能排除了 0.8 点、
   另一族只排除 13.6 点，**差 17 倍**。本表**必列**该列。
3. **配对不是可选**。逐种子成功率跨 0.29–0.88；不配对时 15 种子 SE≈0.062，
   配对后 ≈0.012。且**配对的两侧必须同机器、同代码代**。

**判据**（`docs/测试规范.md` §4 / 各 config 的预注册节）：
`|t| ≥ 临界值(df)` ⟹ 有可测差异；否则**报「测不出」**，不报「没影响」。

## 5. 什么是**结构性**不可测（死结）

```
想测改特征 ⟹ 必须改 edge_dim/node_dim
         ⟹ 变窄补零救不回（只能救变宽）
         ⟹ 必须从零训
         ⟹ 族内 SD ≈ 0.2（BC 族只有 0.0086）
         ⟹ 可检测效应 0.17
         ⟹ 测不出
```

**两个族的分辨率差 20 倍**：

| 族 | 可检测效应（n=5） |
|---|---|
| BC（`cmax`/`ent01_rerun`） | **0.0081 ~ 0.0106** |
| 从零（`clean`/`scratch`） | **0.06 ~ 0.17** |

⟹ **只能测「不改维度」的旋钮**（改完仍能带 BC 起点）。
判据：起臂前跑三条预检（差异字段恰好 1 / 维度不变 / **BC 四项全 0**）。

### 算一算：多大的 n 才够

BC 族 `Δ_s` SD —— **实测 n=15 时是 0.0137**（n=5 时约 0.009~0.016，随族不同）。
要测出 Δ 所需的 n（`n ≈ (t_crit × SD / Δ)²`，`SD=0.0137` 代入）：

| 想测出的 Δ | n |
|---|---|
| 0.005（0.5 点） | **> 40** |
| 0.0075（0.75 点） | **> 18** |
| 0.010（1.0 点） | > 10 |
| 0.020（2.0 点） | > 6 |

⚠ 我第一版写的 SD≈0.010 是**手抄的旧估计**；n=15 实测是 **0.0137**
（主表 #2/#3 的 SD 0.0098/0.0106 是**各臂自己的** Δ_s SD，不是族级常数）。

⟹ **主表 #2/#3/#4 那些 +0.5 点量级的效应，在合理成本内根本不可测。**
继续扫同类旋钮**大概率还是「测不出」**。

## 6. 怎么加一行

1. 实验**跑之前**：在 config 的注释里写死**预注册判据**（窗口、临界、单向还是双向）。
2. 判读用 `scripts/diag/paired_verdict.py`（**族级、带窗口**），**自己另写一份会被口径差异坑**
   （§二十五 就是我的临时脚本只用 u30 单点、算出 7 倍差异）。
3. 补这一行：**Δ / SD / t / 临界 / 可检测效应 / 判决**。
4. **「测不出」也要写**，并带上可检测效应 —— 那是有界负结论，是消融表的主体。

⚠ **不要**把"某条臂显著"直接写成配置级结论：问「配置好不好」用**族级**配对，
逐臂只回答「这条运行高不高」（记忆 `first-config-to-beat-the-expert`）。
