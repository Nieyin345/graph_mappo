# v7.5 短期信道速率量级验证（2026-10-08）

> 2026-10-09 复核：在新服务器用当前代码重跑全部六场景，192 行静态数据及 24 行动态汇总逐字段与本报告原数据一致。修正了验证脚本的无效样本处理、块长单位和失败退出行为，新增源码哈希。详见《短期速率复核_20261009.md》。本报告仍仅代表受控合成天气验证。

## 结论

当前实现通过了本次受控场景的量级与趋势检查。没有发现需要通过人为调节统一损耗来压低或抬高速率的证据。HAP→GS 为约 0.1–1 Mbit/s，星地、星空及较短星间链路主要为 kbit/s；远距离链路受有限块长约束可降为零。结果可表述为“与既有研究的量级及传播趋势相容”，尚不能表述为“同参数复现实验”或“已通过真实天气标定”。

尤其需要区分渐近代理率和最终有限密钥产出：4000 km 星间链路在本配置下仍有约 89 bit/s 的渐近代理，但 60 s、300 s 的有限密钥估计均为零。这不是数值崩溃，也不能把正代理值当成可交付密钥。

## 1. 实验设置与数据口径

- 使用已修复的 v7.5 `RateModelV7`、`compute_block`、有限密钥函数及真实轨道/几何计算；没有调整主模型硬件参数。
- 2023-01-01 UTC 起的 24 h，1440 个 60 s 时隙，每槽 4 个几何子步。
- 3 个合成城市站点：London、Beijing、Denver；使用项目 DEM 表高程，分别为 16、47、1599 m。每站一个静止 20 km HAP。
- Walker 60 星，550 km；保留全部 2133 条候选链路：3 条 HAP–GS、180 条 SAT–GS、180 条 SAT–HAP、1770 条 SAT–SAT。
- 1550 nm、100 MHz；束腰半径 0.1 m；GS 接收口径 0.6 m，HAP/SAT 接收口径 0.5 m；GS 探测效率 85%，HAP/SAT 为 25%；完整参数保存在 `metadata.json`。
- 每条接触独立评估，不执行网络端口匹配或业务调度。多链路密钥总和表示潜在产能，不是可同时实现的网络吞吐量。
- 动态时间序列在接触开始扣除 5 s 捕获时间；连续接触每 60 s 或 300 s 关闭有限密钥块，接触结束或试验结束也关闭剩余块。云遮挡后保留脉冲数为零，块时间仍推进。
- 静态表在固定距离/仰角和晴夜背景下分别估计 60 s、300 s 密钥率，不计初始捕获；不能把该表的固定几何条件当成真实整次卫星过境。
- 固定每块安全参数的模型期望计数性能估计；不是全网实际计数下的安全认证。

**天气为受控合成输入。** 服务器现存旧天气 CSV 缺少新版必需的来源标记和 ERA5 网格地形高度，本次没有为这些文件补造来源或假设高度来冒充真实天气验证。直接给定 HV 系数 A，因此本次速率场景不验证 MOST→HV 在真实天气下的统计分布；高程 P/T 修正另有回归测试。

|---|---:|---:|---:|---:|
| clear | 1.1×10^−14 | 0.1 | 0 | 0 |
| aerosol | 1.1×10^−14 | 0.8 | 0 | 0 |
| strong_turbulence | 1×10^−13 | 0.1 | 0 | 0 |

高云垂直光学厚度 0.3；低中云采用模型原有站点共享 Gaussian-Markov 过程，相关时间 3600 s，种子 2023。`strong_turbulence` 表示增强近地湍流的压力测试，并非所有几何点都进入 Rytov 强起伏域。50% 是输入遮挡概率，单次 24 h 实现不要求正好遮挡一半时间。

## 3. 24 h 动态结果

下表是晴空场景中**可见且 60 s 条件速率为正**的槽的分位数。零值另列比例，避免只报正样本掩盖链路不可成码的问题。

| 链路 | 正速率槽占可见槽 | 正样本 P10 / 中位数 / P90（kbit/s） |
|---|---:|---:|
| HAP→GS | 100% | 1012.71 / 1013.43 / 1036.79 |
| SAT→GS | 78.14% | 0.155 / 1.734 / 10.885 |
| SAT→HAP | 74.95% | 0.221 / 1.323 / 5.370 |
| SAT→SAT | 11.14% | 0.109 / 0.753 / 6.795 |

星间候选对包含大量接近距离上限的链路；**几何可见不等于短块内能提取有限密钥**。11.14% 是可见槽中 60 s 条件成码比例，不是最终网络服务成功率。

采用 300 s 块、云门控和 5 s 捕获后，24 h 总产出相对晴空如下；每类分别归一化，未混合成网络吞吐：

| 场景 | HAP→GS | SAT→GS | SAT→HAP / SAT→SAT |
|---|---:|---:|---:|
| 晴空 | 100% | 100% | 100% |
| 气溶胶增强 | 82.92% | 72.13% | 100% |
| 湍流增强 | 10.82% | 3.11% | 100% |
| 薄高云 | 73.46% | 58.65% | 100% |
| 低中云概率 50% | 50.61% | 54.46% | 100% |
| 完全低中云遮挡 | 0 | 0 | 100% |

这验证了模型能够反映天气、云与湍流的影响。上层两类链路不随地面天气变化是当前“上层残余分子柱/背景固定、地面湍流与气溶胶不延伸至上层”的建模假设，不是对所有真实空间天气影响的验证。

增强湍流场景中，SAT→GS 有 **13.65% 的可见几何子步**落在 V_R≥1 的域外；其速率采用文档规定的工程外推，不能用于证明该区域的绝对物理精度。其余五种场景的此次可见子步均在域内；全部动态场景未出现有界矩不相容样本。

晴空 864 次星地几何接触（含零产出接触）的“接触产出/接触时长”非加权平均约 2.809 kbit/s，最大约 6.860 kbit/s。该值包含本脚本的 300 s 分块与捕获规则，不是 Liao 论文过境几何的复现。

## 4. 文献对照及合理性判断

### SAT→GS：量级相容，尚未同参数复现

Liao 等在一次 645–1200 km、273 s 的过境中得到 300,939 bit 最终密钥，即平均约 1.102 kbit/s；不是“1200 km 瞬时速率 1.1 kbit/s”。实验采用 848.6 nm、100 MHz、1 m 接收望远镜，与本文 1550 nm、0.6 m、85% 探测效率等配置不同。本次约 1–数 kbit/s 的典型星地结果与其数量级相容；天顶 18 kbit/s 不应拿来直接除以该过境均值判定模型高估。[作者全文](https://arxiv.org/pdf/1707.00542)

### HAP→GS：约 1 Mbit/s 暂无明显数量级矛盾，但不能声称已有对应实测

Chu 等分析了 20 km HAP、1550 nm、0.4 m 地面接收口径和 5 μrad 指向抖动，常规仰角下晴空链路预算较充裕。该文主要给损耗和 QBER，不是本模型 Mbit/s 安全率的直接证据。[作者机构全文](https://pure.hw.ac.uk/ws/portalfiles/portal/45461630/Chu_2021_Quantum_Sci._Technol._6_035009.pdf)

Karakosta 等仿真的 35 km 垂直 HAP→GS SKR 为 112.01 kbit/s，但用 80 MHz、平均光子数 0.01、40 cm 接收口径、AO 阶数 6、固定 4% QBER 和简化密钥率表达式；与本项目三强度 0.62/0.24/0、60 cm 口径及有限块方法不同。不能把 112 kbit/s 当成 HAP 通用速率上限，也不能仅靠这些参数差异声称精确解释了所有差值。[作者全文，表 1–3、式 13–14](https://arxiv.org/pdf/2412.03356)

### SAT→HAP、SAT→SAT：目前支持模型自洽，实测佐证不足

本次未核实到可同设备、同协议比较的这两类在轨安全率实验。衍射、指向误差、接收效率及有限块门限导致的下降趋势合理，但“已经与在轨实验吻合”缺乏证据。详见同目录《短期速率文献核对_20261008.md》。

## 5. 是否需要继续改模型

**本轮结果不支持继续增加物理复杂度或人为调速。** 保留当前主模型，论文中明确设备参数与有限块口径即可。

有两项结果应落实到论文实验解释：

1. 最终评价用有限密钥实际释放量；不能用 `k_proxy>0` 代表一定能生成有限密钥，尤其是长距离 ISL。
2. 增强湍流域外比例必须报告；不要把外推数据描述为经过精确验证的强湍流物理模型。

下一阶段若要声称“真实天气驱动性能”，应重新获取符合当前来源、时间戳和 ERA5 高程规范的短期输入，再走生产构建入口。此次只完成受控天气与轨道联合测试，没有完成真实天气标定、多随机种子云统计或全网调度评估。
