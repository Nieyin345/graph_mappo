# 信道与系统模型修订与历史记录

> 本文件保存从主规范中迁出的版本摘要、旧模型说明和历史数值。它们用于追踪建模过程，不代表当前主模型。当前规范见 `信道与系统模型规范_定稿草稿_20261005.md`。

## 1. 历史版本摘要

**v7.4 修订摘要：**
1. **§4.1 云相关性假设降级为显式特例**：同站共享阈值模型明确标注为“最大正相关简化”；新增带可调空间相关系数的 Gaussian-copula 对照，避免把不同方位链路强制成嵌套可用事件。
2. **§5.1 补齐遮云门控的信息层次**：主基线要求终端通过独立 beacon/LOS 标记在动作后识别遮挡并暂停量子发送或排除时间标签；同时增加“信号消失但背景仍计数”的无门控对照。
3. **§5.3 训练库存改用 block 聚合后的渐近代理**：逐子步 $\sum_jN_jr_\infty(t_j)$ 仅用于 reward shaping；真正进入训练库存的代理释放量由整块聚合统计一次计算，进一步对齐最终 finite-key 评估。
4. **§3.4 修正 Beta 边界语义**：$S_I=(1-m_c)/m_c$ 是连续 Beta 不可达但物理可达的端点 Bernoulli 边界；只有严格超过该上界才是物理矩不相容。
5. **§3.2/§3.4 修正文献表述**：Karakosta A7 为 Gaussian 波前曲率、A8 为 Gouy 相位，只能说明自由空间波型处于过渡区，不能作为湍流闪烁公式；定量 Gaussian 对照须另用有限 Gaussian 光束湍流表达式。
6. **§7.1 修正历史结论**：旧损耗分解列出的因子仅约 25.8 dB，与“约 38 dB”不闭合；删除对 HAP 可用性和模型正确性的过强判断，并把 550 km 传播方向统一为 SAT→GS 下行。

> **版本说明：** 下列 v7.3 / v7.2 / v7.1 摘要保留为历史审查记录；凡与 v7.4 正文冲突之处，均以 v7.4 为准。

**v7.3 修订摘要：**
1. **§3.4 PDT 主基线改为有界 Beta 两矩匹配**：不再为了保留截断对数正态而裁小物理闪烁指数；只要 $(m_c,S_I)$ 满足 $0\le S_I<(1-m_c)/m_c$，即精确保持 $\mathbb E[U]=m_c$ 与 $\operatorname{Var}(U)/\mathbb E[U]^2=S_I$。截断对数正态仅保留为敏感性对照。
2. **§3.1 海拔与地形参考面闭合**：绝对海拔 $h$ 与离地高度 $z=h-h_{\rm GS}$ 分开；主基线采用 AGL-HV 剖面，并把绝对海拔 HV 作为高原站敏感性；同时显式区分真实站点海拔与 ERA5 网格地形海拔。
3. **§4.1/§5.1 云模型统一**：主模型使用站点共享的 Gaussian-Markov 潜变量，并按各链路各子步自己的 $f_e(t_j)$ 阈值化为 LOS 状态；$fN$ 比例模式仅作 smooth-weather 对照；明确调度器可观测信息与真实云状态分离。
4. **§5.1 捕获窗口修正**：首槽捕获占用 $(1-\gamma)\Delta=t_{\rm acq}$，有效通光窗口为后续 $\gamma\Delta$；子步只采样实际有效窗口。
5. **§5.2 调度槽与有限密钥块解耦**：$\Delta_{\rm sched}=60$ s 仅是调度粒度；有限密钥统计按独立的 QKD block 聚合后一次施加安全界，避免每分钟重复支付 finite-key penalty。
6. **§5.3 训练/评估时序统一**：渐近代理仍可提供稠密学习信号，但未关闭 block 的代理密钥不得提前进入可消费库存；训练与最终 finite-key 评估使用相同的 block 边界与释放时刻。

> **版本说明：** 下列 v7.2 / v7.1 摘要仅保留为历史审查记录；凡与 v7.3 正文冲突之处，均以 v7.3 为准。

**v7.2 修订摘要（针对 2026-10-07 第三轮外部审查，按"模型数学闭合优先"排序）：**
1. **§3.4 PDT 矩匹配（P0）**：截断对数正态原按"未截断均值 = $m_c$ 再截断"定参，导致截断后 $\mathbb E[U]\neq m_c$、$\operatorname{Var}/{\mathbb E^2}\neq S_I$（HAP 天顶实测 $\mathbb E[U]$ 低 2.6%、点接收区 11.9%）。改为**截断后两矩匹配**；并给出该族的**可行性上界** $S_{\max}(m_c)$（$m_c=0.95$ 时仅 0.0025，HAP 目标 $S_I=0.0046$ 超界）——故规定**保 $\mathbb E[U]=m_c$ 精确、$S_I$ 夹到可达上界**，保上界分布族（Beta）列后续。
2. **§3.4 β₀² 口径（P0）**：厘清 Andrews 三量（平面波 $\sigma_{R,\rm pl}^2$、球面波 $\beta_0^2=0.4065\sigma_{R,\rm pl}^2$、下行球面 B2）；结论 $V_R$（B2）即 $\beta_0^2$，代入 B5 **不再乘 0.4065**；标注为"推得、须对原文复核"，并加口径敏感性。
3. **§4.1 云量语义（P0/重新定义）**：ERA5 云量是 **grid-box 空间覆盖率**，非"槽内通光时间比例"；主模型改定义为 $P(\text{LOS 通光}\mid\text{state})$ 并生成**相关二值/Markov** 槽内状态，确定性比例模式**降级为期望代理**。
4. **§3.1 GS 海拔（高优先级）**：ERA5 `surface_pressure` 是地形表面值，基线原按 $h_0=0$ 积分 ⟹ 参考面错配；改为**用真实站位海拔**，一致修改气柱/湍流/几何/MOST 参考面。
5. **§5.1 捕获时间（高优先级）**：$\gamma$ 改由真实捕获时间定 $\gamma=\max(0,1-t_{\rm acq}/\Delta)$（典型几秒 ⟹ $\approx0.9$）；$\gamma=0$（整槽无脉冲）降为极端对照，不再作主场景默认。
6. **§7.1 Micius 对比（文案修正）**：[Liao2017] 一次过境**最终密钥平均约 1.1 kbps**，非几十 kbps；"2.9 kbps 低一个数量级"不成立（硬件、口径、统计口径均不同）。
7. **§7 新增**：PDT 矩匹配上界与 Beta 族、海拔一致性、云 Markov、$\beta_0^2$ 原文复核、背景/吸收工程化 等交付项。


**v7.1 修订摘要（针对 2026-10-07 外部审查四点，均已实测；2026-10-07 二次审查修订第 1/2/3 条措辞与公式）：**
1. **孔径平均**（§3.4）：判据用**弱起伏**相关宽度 $\rho_c=\sqrt{\lambda L}$（Karakosta 式 B3，**不切 B4 强分支**——B3/B4 在 $V_R=1$ 处不连续）。HAP–GS 生效（$D=0.6$ m $>\rho_c\approx0.18$ m），点值截断均值偏差 11.9% 降至 2.7%；SAT–GS 不启用（$D<\rho_c\approx0.92$ m），取点接收 $S_I=\min(V_R,1)$。$\beta_0^2$ 口径见 §3.4（一致性选择，非逐字复现）。
2. **HAP 球面波核**（§3.2）：$L/Z_R\approx0.99$（天顶 $20$ km vs $Z_R=20.27$ km）落在**瑞利距离附近的过渡区**，**不是远场**。基线暂用球面波核，但列为**待验证的工程近似**；换平面波核会把 HAP $V_R$ 抬高 34%、速率抬高约 4%（仅作方向参考，非"球面波误差"）。待用有出处的有限束宽 Gaussian 模型定量对照。
3. **弱起伏域覆盖**（§3.4/§7）：实测全年 45 站，可见样本域外率 SAT–GS **4.13%**（集中于 15–30° 与干热/高原站），HAP–GS 天顶 **0.06%**；域外 SAT–GS 速率恒 0 是**几何/掩码主导**，不作为域外模型正确的证据；域外 HAP–GS 68%（15°）仍为正。域外闭合 $\min(V_R,1)$ 是**经验外推**，非已验证的强起伏模型。
4. **槽内时间分辨**（§5.1）：几何每 60 s 槽移动可达 ~8° 仰角，槽起点单点采样偏差**有方向**——SAT–GS 低/中仰角高估 14–135%，近切 SAT–SAT 低估约 68%（不能概括为"一律高估"）；引入 `intra_slot_samples`（子步中点，n≥4 收敛 <1%）。首槽捕获窗口与子步时间轴的一致性列为 §7 待办。

## 2. 历史数值与旧结论

### 7.1 历史实测的适用域与解释边界（v7.1/v7.2；v7.4 需重算）

> **重要：** 本节数值均来自 v7.1/v7.2 的旧数据管线，用于保留诊断依据。v7.4 已改变 PDT 边界处理、GS 海拔参考面、云相关结构、LOS 门控统计、训练代理聚合方式和 finite-key block 划分，因此本节所有绝对速率、域外率、链路间倍率和有限密钥距离边界都必须重算；在重算完成前不得把这些历史数值作为 v7.4 的最终结果。

**弱起伏域覆盖率**（全年 45 站 ERA5，可见样本中 $V_R\ge1$ 的占比）：
- **SAT–GS：4.13%**（强分层——仰角 15–20° 段 9.86%、20–30° 段 2.39%，45° 以上 <0.2%；站间 Almaty 26%、Santiago 19%、Madrid 14%，高原/干热站最高；季节差异仅 ~1.5×）。域外 SAT–GS 样本**速率恒为 0**（几何/仰角掩码主导，**非**域外本身所致）。⚠ **该零值不能反过来当作"域外外推正确"的证据**——它由低仰角几何决定，与外推闭式的取值无关；域外结果不得与域内结果合并陈述。
- **HAP–GS（基线静态天顶）：0.06%**；15° 斜程压力测试下 9.5%。域外 HAP–GS 样本 **68%（15°）/ 11%（天顶）仍有正密钥**（HAP 高信噪比，$V_R\ge1$ 不致断键）。

**SAT–SAT 成码距离（历史 60 s-block 结果）**：旧 v7.1/v7.2 管线在每 60 s 独立施加 finite-key penalty 时得到约 $L\lesssim1800$ km 成码、$\ge2000$ km 时 $\ell=0$。该数值不是物理断链，也**不再视为 v7.4 基线边界**；v7.4 必须分别在 60 s 独立块与连续会话聚合块下重算。$L\le4500$ km 仍仅是几何视距门限，不能据此宣称有限密钥可达 4500 km。

**绝对量级标定（历史诊断，v7.4 已发现旧损耗预算不闭合）**：旧数据集 SAT–GS **正速率样本条件平均**约 2.9 kbps。⚠ **不得简单说成“比 Micius 低一个数量级”**——Micius（[Liao2017]）报告的一次过境最终安全密钥平均约 1.1 kbps，且硬件与统计口径均不同。

旧文曾写“天顶、晴空总损耗约 38 dB”，但同一句实际列出的因子并不能得到 38 dB。按所列数值：
- 几何截获 $m_c=0.0195$：约 17.1 dB；
- GS 接收光学 $\eta_{\rm rx}^{\rm opt}=0.45$：约 3.5 dB；
- tip/tilt 后 SMF 耦合 $\eta_{\rm smf}=0.46$：约 3.4 dB；
- 发射光学 $\eta_{\rm tx}^{\rm opt}=0.80$：约 1.0 dB；
- GS 探测效率 $\eta_{\rm det}=0.85$：约 0.7 dB；
- 若再计旧报告晴空透过率 $\eta_{\rm clear}\approx0.954$：约 0.2 dB。

以上合计仅约 **25.8 dB**，其中几何截获约占所列损耗的 **66%**。因此“约 38 dB”在当前文档中**没有由已列因子闭合**；若代码中确有另外约 12.2 dB 的损耗，必须逐项列出来源并检查是否与 $m_c$、SMF、光学效率或大气损耗重复计数，否则删除 38 dB 结论。$m_c$ 对应的是 SAT→GS **550 km 下行传播**后的光斑与 0.6 m GS 接收口径之比；后续损耗预算统一按该下行方向表述。

SAT–GS 由卫星发射、地面接收，故使用 GS 探测效率 0.85，而非 SAT 的 0.25。论文不得宣称绝对密钥率已对标 Micius；更有说服力的验证是把参数改到接近 [Liao2017] 的波长、口径、发散角、探测效率和轨道条件，复现 loss-vs-elevation 与 sifted-rate-vs-range 曲线。

**HAP 主导（历史结果，需用 v7.4 重算）**：旧管线得到 HAP–GS 正速率均值 622 kbps、SAT–GS 2.9 kbps，约相差 200×。这个结果**不能作为模型正确性的证据**。HAP 静态部署和较短距离只意味着几何可见窗口通常更稳定；HAP–GS 仍然穿越对流层，仍受低/中云遮挡、高云衰减、湍流、背景和门控假设影响，几何持续可见不代表全年光学链路持续可用。v7.4 必须在新的云相关性、LOS 门控/无门控、PDT 和 block 设置下重算该倍率。

策略层仍需检查是否过度依赖 HAP：论文必须给出四类链路的使用分布、HAP 不可用时的替代行为，以及不同 $\rho_{\rm sp}$ 下链路替代机会是否改变。若“躺赢 HAP”只在最大正相关或理想门控假设下出现，应明确报告这一条件。

**近地湍流标高**：MOST→HV 工程连接固定 100 m 标高，未随边界层高度变化（§3.1）；对 SAT–GS 影响有限（下行 Rytov 核近地权重小），主要影响 HAP–GS 的 $r_0$，纳入敏感性检查。

**背景与吸收仍偏工程化（建议补充）**：SAT–HAP / SAT–SAT 的背景（SAT–HAP 白天取地面昼值的 0.054、SAT–SAT 固定 $1.5\times10^{-7}$）与 1550 nm 大气吸收（$\tau_{\rm abs}=0.0193$ 的固定气柱参数化）均为**量级近似**，非实测标定；<2000 km 的绝对密钥率受其影响。须在 §7 以不同背景/吸收取值扫描，或将 [Liao2017] 同参数复现作为锚点。

## 3. v7.5 收敛说明

**历史统计措辞修正：**旧分析中“84.1% 的样本密钥量不同”表述不成立。实际统计仅支持：在可见 SAT–GS 样本中，**$0<f<1$ 的样本占 84.1%**（另有 $f=0$ 占 15.9%、$f=1$ 占 0%）。这只能说明大多数样本具有中间通光概率，不能直接等价为“84.1% 的样本在两种云处理下得到不同密钥量”。

v7.5 起主规范不再保留逐轮审查过程。主要收敛为：固定站点尺度、时间持续的共享云遮挡主模型；移除 Gaussian-copula 主文扩展；捕获时间限定在单槽内；训练库存继续采用 block 聚合渐近代理；HAP 波型与孔径平均只保留一项核心工程近似及对应文献/代表性对照。当前训练配置显式取 $T_{\rm block}^{\max}=300$ s，作为研究工程基线而非文献常数；最终结果必须与 60 s 独立块和连续会话聚合块共同报告。
