3. **第三章保守润色**。压缩重复、拆解长句，并明确无向共享密钥与方向对称速率是两件不同的事。后者仍是本稿既定近似，不被共享性自动推出。
4. **实质性措辞校正**。将“两两不可区分”收敛为“未显示一致结构优势”，将“匹配联合似然”限定为“选弧序列联合似然”，将“最优差距”限定为“相对松弛上界的缺口”。这些是论断范围修正，不只是同义词替换。
5. **可确定的内部问题直接修正**。按约束名称解释 LP；重述 19.5 dB 与文献区间的差值；将“整个区间落入”改为量级接近。没有变更原始参数和实验观测。

第一章段落组织有所调整，第二章小节结构保留，III-A–D 及 III-B 的七个子部分顺序未变。未把正文内容转移到补充材料。
