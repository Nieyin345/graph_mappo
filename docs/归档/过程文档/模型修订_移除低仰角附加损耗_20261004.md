# 模型修订：移除主模型中的低仰角经验附加损耗

日期：2026-10-04。基线：用户指定的 `论文初稿_中文_v5_20261003.md`、当前 40 页论文引用版 PPT、`tools/channel_v2/rate_model_v2.py` 与 `global_v2c` 的有限码长构建流程。

## 1. 本次修改

主模型默认 `ParamsV2.kappa_x_db = 0.0`，地面链路诊断输出 `xs = 1`；总透过率不再乘以非平凡的经验附加损耗。

\[
\bar\eta_e=\langle\eta_{\mathrm{bp}}\rangle\eta_{\mathrm{sys}}\eta_\phi\eta_{\mathrm{mol}}\eta_{\mathrm{aer}}\eta_{\mathrm{ci}}.
\]

原有衍射、湍流展宽、指向抖动、SMF 波前耦合、分子/气溶胶消光、云层处理以及有限码长协议均保留。低仰角仍通过传播距离、大气路径及波前耦合影响密钥率。

移除理由是原残差项缺少独立识别，且与显式湍流损耗存在**潜在重叠**，并非已经证明所有附加损耗均重复，也不表示近地平线传播已被完整描述。

正系数仅保留为显式敏感性设置：

```python
ParamsV2()                    # 主模型：kappa_x_db=0.0
ParamsV2(kappa_x_db=1.0)      # 显式历史参数/敏感性情景，不是主模型
```

构建器新增 `--kappa-x-db`；负值、NaN、无穷大均拒绝。新输出元数据记录 `model_revision`、`rate_model_variant`、`low_elevation_excess_enabled`，原有 `rate_model_params` 中仍记录具体系数。默认输出改为新的 `dataset/global_v2d`，避免默认指向既有数据目录；原输出保护机制保留。

**云层选项的默认值未改动。** 为保持当前正式数据的 `coverage_layers` 口径，新建正式数据必须按下文命令显式指定该选项；不能只依赖构建器的历史 `binary_total` 默认值。

## 3. 测试范围

在 `qkd` 科研服务器、`/opt/qkd/venv/bin/python` 下运行 9 项小规模回归测试：默认关闭；非法参数拒绝；地面链路物理乘积；敏感性因子比例；标量与天顶边界；高空两类链路不变；有限码长接口；构建器非法参数拒绝；与修改前源代码的显式历史参数复现。

地面链路测试采用 5°、10°、20°、30°、60°、90° 仰角网格，覆盖 SAT–GS 与 HAP–GS；非地面链路检查 SAT–HAP 与 SAT–SAT。旧源码对照检查透过率达到浮点容差一致、测试网格上的有限码长速率完全一致。

测试通过仅表示此次代码修改满足所列回归条件，不是完整物理验证、全年数据验证或网络实验复现。生产测试目录未附旧源快照时，历史对照一项会标记跳过；发布检查在隔离目录显式提供了旧源快照并运行该项。

## 4. 后续重建方案（本次未执行）

先检查输入：

```bash
cd /opt/qkd/graph_mappo
/opt/qkd/venv/bin/python tools/dataset_v2/build_dataset_v2.py \
  --check-inputs --cloud-model coverage_layers --kappa-x-db 0
```

再经确认后以脱离前台的受控任务构建新目录，命令主体为：

```bash
/opt/qkd/venv/bin/python tools/dataset_v2/build_dataset_v2.py \
  --out dataset/global_v2d --days 365 --workers 2 \
  --protocol finite_key --cloud-model coverage_layers \
  --tau-cirrus 0.3 --cloud-seed 2023 --kappa-x-db 0
```

不要加 `--overwrite`，不要覆盖 `global_v2c`。构建完成后核对元数据、候选/保留链路、正速率比例及速率分布，并重新估计归一化统计。随后显式切换数据配置，再重跑图 3、基线、训练与评估，不能沿用旧结果作为新模型结果。

敏感性情景必须另用新的目录，例如 `dataset/sensitivity_kappa1_20261004`，并显式传 `--kappa-x-db 1`；其余构建参数应与主模型保持一致。

本次没有启动全年数据重建、相位屏 Monte Carlo 或训练任务。
