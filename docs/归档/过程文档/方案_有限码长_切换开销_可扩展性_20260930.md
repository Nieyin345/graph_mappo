# 重建数据集前的约定（2026-09-30，第二版）

## 1. 有限码长

- 采用固定的计算方式：每个时隙的探测数据单独做后处理，块长为 $N=f_{\mathrm{rep}}\Delta=6\times10^9$ 个脉冲。
- 公式：两诱骗态高效 BB84 的有限码长安全界 [Lim 2014]，统计涨落用乘性 Chernoff 界 [Sidhu 2022]。完整公式见附录 C 的 (C2)–(C7)。
- 协议参数对所有链路取同一组固定值：
  - 强度 $0.62/0.24/0$，强度概率 $0.49/0.40/0.11$，X 基概率 $0.71$；
  - $f_{\mathrm{EC}}=1.16$，$\varepsilon_{\mathrm{sec}}=10^{-9}$，$\varepsilon_{\mathrm{cor}}=10^{-15}$。
  - 这组参数以夜间 −36 dB 的 S–G 链路为参考优化一次，之后不再改变。
- 典型链路的时隙密钥率（脚本 `q/fk/fk_fixed2.py`）：

| 链路 | 渐近公式 | 有限码长 |
|---|---|---|
| H–G，仰角 30° | 489 kbps | 300 kbps |
| S–G，仰角 60° | 7.8 kbps | 3.7 kbps |
| S–G，仰角 30° | 3.2 kbps | 1.08 kbps（墨子号过境平均 1.1 kbps） |
| S–G，仰角 15° | 1.7 kbps | 0.28 kbps |
| H–S，白天 | 3.4 kbps | 0.53 kbps |
| S–S，1000 km | 4.5 kbps | 1.73 kbps |

  夜间总透过率低于约 −40 dB 时不再成码。

- 说明：[Sidhu 2022] 论文图 1 使用的参数（X 基概率 0.889/0.9）是按整次过境成块设计的。用于 60 s 的块时，Z 基数据太少，高损耗链路全部为零，所以不能直接照搬。

## 2. 切换折减 $\gamma$

- 保持原机制，只改了正文的说法：$\gamma$ 表示扣除重新捕获跟踪、同步校准与信道测试的准备时间后，用于成码的时间比例。
- 取值以后再定，不影响数据集。

## 3. 数据集

- 与以前相同：每条链路每个时隙存一个密钥率，只是改为按第 III-B 节的模型计算，并使用有限码长公式。
- 上一版提出的"改存 $\bar\eta$ 与 $Y_0$"已撤回。
