## 0. 一句话

**在终端受限、密钥池耦合、切换有开销的空天地 QKD 网络里，在线调度的天花板由"看两个时隙"的滚动优化给出；一个结构最简单的图策略，只要以这个滚动优化为教师、用数据聚合 + 切换加权去模仿，就能在线性决策开销下达到教师性能的 95%，而网络结构、强化学习微调、联合解码都不再重要。**

## 1. 逻辑链（每一环对应哪个结果）

1. **问题难、且缺标尺** → 建模 + NP 完全（定理 1）+ 切换感知流体 LP 上界（式 23 切换版）+ 上界紧度证据（附录 B：B 敏感性、整数尝试、先知执行离 UB 1.4–2.3 点）。
2. **现有做法到不了多远** → 启发式 78–83% UB；文献口径的图 RL（从零 / 专家 BC 起步）≈ 专家 +0~+2 点（表 2）。
3. **在线天花板在哪** → 滚动时域 LP（MPC，只用在线信息）.610/.573/.552 = 95/93/92% UB；不看未来速率（persist）几乎不掉（≤0.2 点）；地平线 h=1→3 涨 3–4 点、之后饱和（表 6）⟹ 天花板 ≈ "看两槽"的联合优化。
4. **把天花板蒸馏成在线策略** → MPC 教师 + DAgger（β=1,0.5,0.2,0）+ 切换加权模仿（λ=4）：专家 BC .538 → 教师 BC .561 → DAgger .579 → +λ .582（1×；2×/3× 同趋势）（表 3）。终点 .581/.550/.524 = 91/89/87% UB，MPC 的 95/96/95%，vs 专家 +5.0/+5.6/+5.3（表 2）。
5. **什么不重要**（受控实验，都是正面证据而不是遗憾）：
   - 网络结构：同一示范下 8 种结构两两不可区分，最大配对差 0.9 点（表 4）；
   - PPO 微调：±0.1 点（表 3 末行）；
   - 联合解码：最大权匹配替换贪心，−0.6~+0.3 点，CI 含 0；
   - 保持偏置：粘性加分单调变差（β=8 时 −2.2~−2.7 点）。
6. **剩余 2.6–2.9 点缺口在哪** → 不在解码、不在保持，在"切换到哪条"的跨时隙判断：h=1 的 MPC 低于本文方法（.578 vs .581；.511 vs .524），h=3 高 3 点；模仿诊断：策略对教师新激活弧的召回只有 88–92%（总体 98%）。⟹ 后续工作：蒸馏教师地平线内的激活份额（明确写"本文未做"）。
7. **可部署性与泛化** → 决策时间 60→120 节点 5.2→8.4 ms（线性），专家 28→89，MPC 53→175（p95 295）（表 9）；零样本节点失效 8 种情形保持 专家 +4.4~6.0 / MPC −2.3~3.3（表 7）；零样本跨规模 120→90/60 仍 专家 +2.1~4.2（表 8）。

## 2. 贡献列表（按证据强度排）

1. 建模 + NP 完全 + 切换感知的可计算上界（含正确性证明、等价引理、实现级测试）。
2. 真实数据驱动的 120 节点 SAGIN-QKD 仿真基准（v2 信道、ERA5/CAMS/分层云、有限码长、Walker 星座；参数与输入 md5 可复现）。
3. 训练方法：滚动时域 LP 教师 + DAgger + 切换加权模仿 → 线性开销的在线策略达 MPC 的 95%。
4. 实证结论（受控）：性能由监督信号决定而非结构；在线天花板 ≈ 两槽前瞻的联合优化；学习策略与天花板的缺口定位在跨时隙判断。
5. 泛化与开销：零样本失效/跨规模、决策时间线性。

**不要写的**：结构优势；"优于 MPC"；"快三个数量级"；"深度强化学习方法"（PPO 无贡献，方法本质是模仿）。
