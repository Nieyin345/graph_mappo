# 背景噪声：影响哪些链路 + 代码正确性核查（2026-10-06）

## 一、背景噪声进入 Y0 的路径

统一公式（`rate_model_v2.py:y0()`）：
```
Y0 = η_rx_opt · η_det · N_b  +  n_det · f_dark · Δt
     └──── 背景光项 ────┘       └── 暗计数项 ──┘
N_b = L_b · G · Δλ · Δt / (hν)      # 进接收视场的光子数
```
其中 etendue `G` 是**接收端相关**的，`L_b` 是**链路/光照相关**的。

|---|---|---|---|---|---|---|---|

## 三、结论：影响哪些链路

**背景噪声影响的是「以地面站/空间终端为接收端、其视场指向天空或地球」的链路**：

1. **SAT-GS / HAP-GS（地面站接收）**：白天 102 Hz vs 夜间 40 Hz。**白天背景使 Y0 翻 2.5 倍**（从暗计数主导变背景主导）。但因为 GS 用 **SMF 衍射极限 etendue（3e-12，极小）**，绝对量级只有 ~100 Hz —— **影响轻微**（实测白天速率仅降 0.5~15%）。
2. **SAT-HAP（HAP 接收）**：白天 581 Hz vs 夜间 80 Hz。**白天背景使 Y0 涨 7.3 倍**，是四类里**受影响最大**的。原因：HAP 用**大口径 + 大视场 etendue（1.54e-9，比 GS 大 512 倍）**，且没有 SMF 空间滤波。
3. **SAT-SAT（卫星接收）**：三档差异大 —— umbra 80 Hz、penumbra 100 Hz（都**暗计数主导**）、**sun 档 13617 Hz（背景主导，涨 170 倍）**。sun 档是强日照反照，视场里可能有地球反射光。

**规律**：背景影响 = **（光照档）×（接收端 etendue）**。
- GS 视场小（SMF）⟹ 即使白天也只 ~100 Hz；
- HAP/SAT 视场大（ΩπR²）⟹ 白天/日照档可到 580~13600 Hz。

## 四、代码正确性判定

### ✅ 代码正确计算了背景噪声

逐项核对通过：

1. **光照档选取正确**：GS 用 `sun_rx_deg>0` 判昼夜（`:494`）；SAT-HAP 用 `lb_day×kappa_strat`（平流层压缩，`:504`）；SAT-SAT 用三档 `isl_nb[umbra/penumbra/sun]`（`:513`）。
2. **etendue 分接收端**：GS 用 SMF 衍射极限 `(1.12λ)²`（对应 Häusler 2024 单模接收端）；HAP/SAT 用 `Ωfov·πR²`（`y0():412-414`）。**两者按接收端类型区分，物理上正确**。
3. **量纲自洽**：`L_b[W/m²sr/nm]·G[m²sr]·Δλ[nm]·Δt[s]/hν[J]` = 无量纲光子数 ✓。
4. **`L_b` 出处正确**：6.85e-5 / 1.5e-7 逐字来自 Khanna 2024 Table 1（见另文核实）。

### ⚠️ 三处需要注意（不是 bug，是建模选择）

1. **HAP/SAT 的 etendue 用接收口径 `d_rx`，但 GS 不用**。这是**有意的**——GS 是单模，HAP/SAT 是多模。但代码里 `y0()` 对 SAT-HAP 用 `d_rx["HAP"]=0.5`、对 SAT-SAT 用 `d_rx["SAT"]=0.5`，而 **SAT-GS 的接收端是 GS（d_rx=0.6），却用 SMF etendue**——即**同一个地面站，在 SAT-GS 里是单模接收，这个一致**。✓ 无问题。

2. **SAT-HAP 夜间的 `L_b=0`**（`:504`）。物理上平流层顶夜间不是绝对无光（有气辉、星光），但量级 << 暗计数，取 0 是合理近似。

3. **ISL 的 `sun` 档 Y0=13617 Hz 偏激进**。代码注释自己写了"三档数值是量级假设，待与联合规范核对"（`:136`）。`L_b=1e-4` 是"视场含日照地球"的上限，实际取决于姿态/几何。**这是已知的待定项，不是错。**

## 五、一张图总结

```
背景噪声 = 光照(L_b) × 视场(etendue) × 滤波(Δλ) × 门控(Δt)
             ↑                ↑
          白天/夜/日照      GS小(SMF 3e-12)
                           HAP/SAT大(ΩπR² 1.5e-9, 512×)
```

**受背景影响排序**：SAT-SAT(sun) >> SAT-HAP(白天) > SAT-GS/HAP-GS(白天) > 夜间各类（暗计数主导）。
