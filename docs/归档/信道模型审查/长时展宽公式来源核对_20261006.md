# 长时展宽公式来源核对（2026-10-06）

## 可直接追溯的替代近似

Karakosta-Amarantidou 等《Free-space model for a balloon-based quantum network》arXiv:2412.03356v1 的附录 B8–B9 给出

\[
w_{\rm LT}^2=w_d^2+\frac{3.26L}{k}(S_R)^{6/5},\qquad S_R\equiv\sigma_R^2.
\]

这里 \(L\) 是传播距离；\(w_d\) 是同一距离处的真空高斯光斑半径。注意原文 \(\sigma_R^{12/5}=(\sigma_R^2)^{6/5}\)，不能对方差再取 12/5 次幂。其下行参数 B2 为

\[
S_R=2.25k^{7/6}\sec^{11/6}\zeta\int_{h_r}^{h_t}
C_n^2(h)(h-h_r)^{5/6}
\left(\frac{h_t-h}{h_t-h_r}\right)^{5/6}\,dh.
\]

原文将此作为强起伏推导、兼用于弱湍流近似的表达式；A1 明确使用球面地球斜程，B2 的 sec 高度积分仍采用分层平面大气近似。该文研究气球链路，不能据此声称已验证所有卫星距离。[原文附录 A、B](https://arxiv.org/html/2412.03356v1#A2.SS2)

## 采用建议与限制

- 若采用上式，应称为“采用 Karakosta 等的长时展宽近似”，不是现有 Piazzolla 转述式的代数修正。
- 无湍流时返回纯衍射；量纲为面积；这些仅是必要自洽条件，不是精度验证。
- 该式已是长时光斑，不能再次添加同一湍流束漂贡献；独立机械指向抖动可另处理。
- 首先按文献同参数复现 HAP–GS。用于 SAT–GS 时另与卫星专用模型比较，不宜把气球模型的适用性直接外推为已确证。
- 当前旧式的高度/距离歧义没有因找到替代式而得到解决。不要保留“旧式一定错”或“新式已证明正确”的判断。

## 尚未解决的另一来源差异

卫星研究 *Statistical verifications and deep-learning predictions for satellite-to-ground quantum atmospheric channels*（Communications Physics 5, 225, 2022）式（11）公开索引给出类似 \(4.35\Lambda^{5/6}k^{7/6}(H_{atm}-H_{OGS})^{5/6}\sec^{11/6}\zeta\) 乘归一化高度积分的写法。它与当前草稿的 \(L^{-5/6}\) 写法不同；仅凭索引片段无法确认大气上界的定义及其推导，故本次不将其认定为可直接替换的确定公式。[论文](https://www.nature.com/articles/s42005-022-01002-1)
