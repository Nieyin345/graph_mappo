# 信道模型审查：安全密钥与指定文献核查

核查日期：2026-10-05。对象：`信道与系统模型规范_定稿草稿_20261005.md` 第 3 章及指定参考文献。未修改原文。本次检查仓库根、docs 及路径祖先未发现适用 AGENTS.md。按 research 技能查原始论文和作者机构资料。

## 结论

第 3.1—3.2 节可以作为渐近诱骗态 BB84 网络仿真基线；第 3.3 节不能以当前形式称为有限码长安全界。需要定向修正，无需推翻整个四类链路架构。

## 必须修改

1. **撤回 κ 的论文归属及安全保证。** Sidhu 2023 原文第 II.2 节式 (2) 使用按数据块计算的密钥长度：

   \[
   \ell=\lfloor s_{X,0}+s_{X,1}[1-h_2(\phi_X)]-\lambda_{EC}-6\log_2(21/\epsilon_s)-\log_2(2/\epsilon_c)\rfloor.
   \]

   本次核查该文全文未找到草稿的 `κ=max(0,1−C_stat/sqrt(N_pass) log2(2/ε_sec))`。原文明确需要真空/单光子事件估计、相位误差估计与纠错泄漏；正文没有给出任意乘法缩放可保证安全的结论。草稿也没有定义 C_stat 或给出校准。因此第 7 章 Q3 所称“Sidhu 提出的紧致下界、保证密码学安全”应删除或替换。[Sidhu 原文，式 (2)](https://arxiv.org/html/2301.13209v2)

2. **分清发射脉冲、探测计数、筛后块长。** 天气使接收计数下降，并不直接改变仍在发射的脉冲总数。100 MHz 连续发射 300–600 s 对应 3×10^10–6×10^10 个发射脉冲；原文的默认参数与 10^8–10^10 范围并不自动一致。若有停发或调度占空比，需显式计入。有限密钥效应取决于各基矢、各强度的有效样本，而不只取决于一个 N_pass。[Lim 原文的协议与式 (1)–(5)](https://arxiv.org/pdf/1311.7129)

3. **补齐强度选择概率及产钥定义。** 当前式子以 Q_mu 描述信号强度，却将速率直接乘总脉冲频率；若只有信号态产钥且 f_rep 是所有强度的总频率，还应计入 p_mu。否则应明说 f_rep 是信号态频率，或说明渐近 p_mu→1 假设。有限块还必须给 p_mu、p_nu、p_0 和基矢概率；这些决定估计样本数。[Ma 原文](https://arxiv.org/pdf/quant-ph/0503005)、[Lim 原文](https://arxiv.org/pdf/1311.7129)

4. **按块汇总统计，再计算安全密钥。** 对一个过境块，先累计分强度分基矢的探测数和错误数；不能在没有证明的情况下，把每秒渐近最优产钥量积分再减一个只依赖 N 的常数当作同一块的安全界。若逐时隙各自提取，则每个时隙都承担有限样本与安全参数开销。SIDHU 的选窗讨论明确表明：加入低仰角样本虽增加块长，也会提高块误码，未必增加最终密钥。[Sidhu II.2](https://arxiv.org/html/2301.13209v2)

5. **区分单块与全系统安全参数。** Lim 使用 ε_sec 和 ε_cor 两部分安全条件；草稿只写 ε_sec=10^-10 为全系统失效界不充分。多块、多链路组成系统需要说明安全预算组合及经典认证假设。[Lim 原文](https://arxiv.org/pdf/1311.7129)

## 可以保留，但需注明边界

- 真空+弱诱骗态的 Y1 下界和 e1 上界与 Ma 式 (34)–(37) 的渐近结构吻合。应明确使用 Y1^L、e1^U；Y1^L≤0 或相位误差上界无法支撑产钥时输出零，避免除零或熵函数越域。
- Q_mu≈Y0+1−exp(−mu eta) 是低背景近似；独立背景与信号点击的合并概率可写作 1−(1−Y0)exp(−mu eta)。Y0≈2p_dark+n_bg 也应注明小概率与探测器数量约定。Lim 仿真模型使用对应的乘积式结构。
- 固定 mu、nu 适用于网络基线；不能在没有本系统扫参证据时宣称固定值在天顶最优、损失固定为 10%–20%。

这些结论对应 [Ma 原文](https://arxiv.org/pdf/quant-ph/0503005) 与 [Lim 原文](https://arxiv.org/pdf/1311.7129)。

## 建议的最小实现路线

研究重点若为网络调度：保留渐近率作为明确标注的训练代理，按真实调度得到的块累计统计，对最终策略以正规有限密钥公式复评。若需要加速，可针对固定协议离线计算查表，但查表误差和是否保守需要验证。不要把任意经验 κ 命名为安全下界。

固定协议下“计算有限密钥”与“寻找最优协议参数”是两项工作。Lim 本身提供简洁公式，不能仅以全局优化昂贵为由断言每次正规有限密钥计算均不可在线实现。
