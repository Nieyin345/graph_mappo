## 1. 【第 1 条】HAP "处于远场" 判断不成立 —— 已改为"待验证近似"

**审查**：$L/Z_R\approx0.99$ 处是瑞利区**过渡带**，不是远场；Gaussian 波前曲率半径约 $2L$，与球面假设的 $L$ 不同；且所谓 Gaussian-beam 对照是构造插值（修订记录 §6.1 自己承认），**不能证明球面波近似正确**。

**核实**：成立。原 §3.2 写了"物理正确极限""实测证明现选正确"——**过度断言**。

**处置**（§3.2）：
- 删除"远场""物理正确极限""已证明"等措辞；
- 球面波核**降级为待验证工程近似**；$L/Z_R\approx0.99$ 明确标注为"瑞利距离附近的过渡区"；
- ±34%/4% 一组数改注为"平面波 vs 球面波之差"，**不是**球面波误差界；
- §7 新增"波型对照"行：用**有出处的有限束宽 Gaussian 模型**（Andrews & Phillips 2005 ch.12；Karakosta A7–A10）对 HAP–GS $\sigma_I^2$ 做定量误差对照。

**代码**：无物理改动（波型未变），仅 docstring 措辞。

## 2. 【第 2 条】孔径平均换元错误 + 符号口径未闭合 —— 真 bug，已修

**审查**：§3.4 把 B4 强起伏宽度写成 $\rho_c^{\rm(strong)}=0.36V_R^{-3/5}\sqrt{\lambda L}$。原文 B4 是 $\sigma_R^{-3/5}$，以 $V_R=\sigma_R^2$ 换元应为 $\mathbf{0.36\,V_R^{-3/10}}\sqrt{\lambda L}$。另外 B7 的 $\beta_0^2=0.4065\sigma_R^2$ 未厘清。

**核实**：**换元错误成立**（我写成了 $V_R^{-3/5}$）。此外我的独立扫描还发现：**B3 与 B4 在 $V_R=1$ 处本身不连续**（相差 $1/0.36\approx2.8$ 倍），用 `D>ρ_c` 作开关会让 σ_I² **在 V_R=1 处跳变**（实测 SAT–GS 跳 Δ≈0.31），与审查"相关宽度不是开关"的判断一致。

**处置**（代码 `tools/channel_v7/model.py`）：
- `correlation_width(L, lam)` 改为**只返回 B3 弱起伏宽度 $\sqrt{\lambda L}$**（去掉会跳变的 B4 分支与 `vr` 参数）；
- `optical_states` 判据相应改为 `D_Rx > √(λL)`；
- docstring 明确：不再切 B4 的原因、β₀² 口径为**一致性选择非逐字复现**。

**实测**：修改后 σ_I² 在全 $V_R$ 区间**跳变数 = 0**（原 1 处），SAT–GS 恒取点接收、HAP–GS 恒取 B5，**四类链路速率逐位不变**（跳变只在 $V_R\ge1$ 的零速率区）。

**文档**（§3.4 + 修订记录）：换元式更正为 $0.36V_R^{-3/10}$；"B4 不作判据"加注；β₀² 口径加注（"不能声称逐字复现"）；SAT–GS "不启用"改称**忽略孔径平均的近似选择**，§7 加 $D_{\rm rx}$ 敏感性。

## 3. 【第 3 条】强起伏处理前后矛盾 —— 已改为"经验外推"

**审查**：一面用 $S_I=\min(V_R,1)$ 处理域外，一面又要求域外经验证模型；$S_I\to1$ 不能证明过渡区可用 `min`；"B5 给 0.42 = 误给"应删；域外算出零密钥不能反证模型正确。

**核实**：成立。原 §3.4 称饱和闭合"更贴切"、隐含已验证；且 `saturating_scint` docstring 还攻击 B5。

**处置**（§3.4 + docstring + §7.1）：
- 明确 $\min(V_R,1)$ 是**经验外推**，**不得称为已验证的强起伏模型**；"强湍流极限趋于有限值不能证明过渡区可用 min"；
- 删除"B5 给 0.42/更贴切"的对比（改为中性陈述：域外无经验证模型，仅给界内可解析取值）；
- §7.1 加警示：**域外 SAT–GS 速率恒 0 不能当作外推正确的证据**（几何决定），域外结果须与域内分开报告。

**代码**：`saturating_scint` 逻辑不变（就是 $\min$），仅 docstring 改措辞。

## 4. 【第 4 条】槽内采样时间定义与验证数字 —— 已修正

**审查**：§5.1 的 $t_\gamma$ 未定义；采样区间与捕获 γ 的关系不清（首槽前半捕获段不应当作通光时间）；"不可见子步计零"语义不明（排除脉冲 vs 保留背景）；修订记录的 SAT–SAT 单点 **5175 vs 参考 16242 是低估 68%，不是"高估 200%"**。

**核实**：全部成立。$t_\gamma$ 是漏改的符号（应为槽起点 $t_0$）；代码确实"只减脉冲数、子步时间轴仍覆盖整槽"；SAT–SAT 那格数字方向写反。

**处置**（§5.1 + 修订记录）：
- $t_\gamma$ → $t_0$（槽起点）并定义 $\Delta$；
- 加注"**采样偏差有方向**"：SAT–GS 低/中仰角高估 14–135%，近切 SAT–SAT 低估 68%（不能概括为"一律高估"）；
- 加注待办：**首槽捕获窗口与子步时间轴一致性**（应只采捕获后的通光子区间或显式门控，不能只减脉冲数）；
- 明确不可见子步语义（本基线按"不含有效信号脉冲"处理，等价排除该段；改"保留背景"会变有限密钥结果，须固定）；
- 修订记录表格/正文的 SAT–SAT 行更正为 −68%，删"约 200%"。

## 5. 【第 5 条】SAT–GS 速率偏低的探测器归因错误 —— 已按实际损耗分解重写

**审查**：SAT–GS 是卫星**发射**、地面**接收**，对应的是 **GS 探测效率 0.85**，不是 SAT 的 0.25；改 SAT 探测效率不能验证这条下行链路的敏感性。

**核实**：成立。实测 SAT–GS 天顶损耗分解（共约 38 dB）：

| 项 | 值 | dB |
|---|---|---|
| 几何截获 $m_c$ | 0.0195 | **17.1（占全部 45%）** |
| GS 接收光学 $\eta_{\rm rx}^{\rm opt}$ | 0.45 | 3.5 |
| tip/tilt 后 SMF $\eta_{\rm smf}$ | 0.46 | 3.4 |
| $\eta_{\rm tx}^{\rm opt}$（SAT 发射） | 0.80 | 1.0 |
| **GS 探测效率** | 0.85 | 0.7 |
| SAT 探测效率 | 0.25 | **本链路不使用** |

**处置**（§7.1）：归因改为**几何截获（m_c）+ 地面接收侧效率**；明确"本链路用 GS 探测效率 0.85，非 SAT 0.25"；灵敏度建议改为针对 $m_c$／$\eta_{\rm rx}^{\rm opt}$／口径。
