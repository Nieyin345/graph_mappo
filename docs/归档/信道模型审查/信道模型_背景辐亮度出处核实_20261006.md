# Khan 2024 背景辐亮度核实 + 白天/夜间影响（2026-10-06 第二次）

## 一、`lb_day` / `lb_night` 出处核实 —— ✅ 抄写正确

**Khanna 2024 (IET Quantum Commun. 5(2):157-163) 原文 Table 1**「Typical radiance data for 785 and 1550 nm」，逐字：

| Atmospheric condition | Hb @ 785 nm | Hb @ **1550 nm** |
| :--- | :--- | :--- |
| Clear day | 3.1 × 10⁻³ | **6.85 × 10⁻⁵** |
| Moonlit clear night | 1.5 × 10⁻⁶ | **1.5 × 10⁻⁷** |
| Moonless clear night | 1.5 × 10⁻⁸ | **1.5 × 10⁻⁸** |

单位 W·m⁻²·Sr⁻¹·nm⁻¹。表格由 arXiv/INSPIRE 镜像的原文 PDF 取得（Wiley 站点被 Cloudflare 挡）。

**我们代码**：
- `lb_day = 6.85e-5` ✅ = Khanna 晴天 1550nm
- `lb_night = 1.5e-7` ✅ = Khanna **有月**晴夜 1550nm

**结论：两个值都逐字抄对，出处标注（"Khanna 2024 Table 1"）属实。**

### 但发现两处需要注意

1. **我们用的是「有月」夜值（1.5e-7），不是「无月」（1.5e-8）**。代码注释写的是 `moonlit clear night` —— 诚实、没错，但**默认场景选了较亮的月夜**。
   - 影响：**几乎没有**。因为暗计数（40 Hz）完全盖过夜天空，1.5e-7 vs 1.5e-8 对 Y0 无可见差别（实测 40.1 vs 40.0 Hz）。所以这个选择**无害**，但如需严谨，可把默认改成无月 1.5e-8。

2. **早先担心的「1.5e-5 差 100×」是虚惊** —— 那是另一篇论文（Cerqueti 学位论文）转述的一般夜空值，与我们引的 Khanna 1550nm 专项值不是一回事。**我们的出处更权威**（Khanna 是 1550nm 专项建模论文）。

## 二、真正的关键：我们的白天背景比文献**低 ~2.4×**，根因是 **etendue 口径**

| 量 | 我们的模型 | 文献 | 差 |
| :--- | :--- | :--- | :--- |
| GS 白天背景等效计数率 | **102 Hz** | 青海湖 1550nm 全天候实测 **240 Hz** | 我们低 2.4× |
| GS etendue | **3.01e-12** m²·sr（SMF 衍射极限 (1.12λ)²） | — | — |

**为什么低**：我们用 **SMF 衍射极限 etendue** `(1.12λ)² ≈ 3e-12`（对应 [Häusler 2024](https://doi.org/10.1117/1.OE.63.4.041211) 的单模接收端）。这个值**与望远镜口径 D 和视场 FOV 无关**——物理上是对的（SMF 只耦合衍射极限内的光）。

**对比**：若按传统 `G = Ωfov·πR²`（D=0.6m、FOV=100µrad）= **2.22e-9**，是 SMF 值的 **737 倍** → 白天背景 45400 Hz，**白天速率会被彻底压垮**。

**两种 etendue 都对，取决于接收端**：
- **SMF 接收端**（我们、Häusler、青海湖实验）：背景被空间滤波压到 ~10² Hz 量级 → 白天可用；
- **多模/大口径 + 无空间滤波**：背景 ~10⁴ Hz → 白天基本不可用。

**所以我们的模型描述的是「SMF 接收端」这个（更先进、更贴近 1550nm 实用系统）的场景**，白天影响小是**物理正确**的。这与文献（青海湖 240 Hz、Nature Photonics「1550nm+SMF 克服白天」）**方向一致**。

### 待定标定问题

我们 102 Hz vs 青海湖 240 Hz 的 2.4× 差距，可能来自：
- FOV / 滤波带宽略小（我们 1nm、FOV=100µrad，青海湖未必相同）；
- 青海湖是**湖面水平链路**（近地强散射），我们是**下行天顶**（更暗）；
- 季节/太阳角不同。

**这不是错，是标定松紧**。是否要在意取决于论文主张：若主打「白天可 QKD」，保守起见应把背景调到 240 Hz 做敏感性。

## 四、总结判定

| 项 | 判定 |
| :--- | :--- |
| `lb_day=6.85e-5`、`lb_night=1.5e-7` 出处 | ✅ **抄写正确**，Khanna 2024 Table 1 |
| 夜值用「有月」而非「无月」 | ⚠️ 无害（暗计数主导），但可改无月更严谨 |
| 白天影响小（0.5~15%） | ✅ **方向正确**（SMF 接收端本就如此），文献支持 |
| 我们的白天背景 102 Hz vs 实测 240 Hz | ⚠️ 偏松 2.4×，建议做敏感性 |
| etendue 用 SMF 衍射极限 | ✅ 物理正确（对应 SMF 接收端） |
| Lund-Shanklin 云表 | ✅ 逐字正确 |

**核心结论**：**参数没错、云没错、白天/夜间方向没错**。唯一可议的是「早上背景偏松 2.4×」，属标定选择，不是 bug。
