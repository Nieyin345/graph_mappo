## 0. 定盘：服务器怎么排（**先读这段再排期**）

| 约束 | 值 | 判据 |
|---|---|---|

照抄 `.tmp/probe_storage_precheck.py` 或 `.tmp/probe_de_precheck.py`。

### 判读口径（**统一，不许各写各的**）

## 2. 逐条细则

### E1 · 去图臂（`model.encoder.num_layers: 3 → 0`）★ 第一优先

**实验设计**
```
臂：      nograph_s{42..46}
对照：    ent01_rerun_s{42..46}（已跑完 u30）
唯一变量：model.encoder.num_layers（3 → 0）
配置：    configs/train_nograph.yaml（待写）
```

**为什么它同时答两个问题**
- **H₁ 的拆分假设**原文：「**GNN 相对纯 MAPPO 无增益 → GNN 贡献不成立**」
  —— 它要的正是「**有消息传递 vs 无消息传递**」。`num_layers: 0` ⟹ `self.layers` 空
  ⟹ 完全没有消息传递。
- **模型合理性**：§体检显示 `encoder.layers` 占 **79.8%** 参数，而 `layers4` 测不出
  （加一层 <1.3 点）⟹ **这块容量既没被证明不足、也没被证明必要**。

**前提已核实（§三十二）**
| 判据 | 结果 |
|---|---|
| 差异字段 | 恰好 1 个（`num_layers`） |
| 维度 | 17 / 44 **不变** |
| BC 暖启动 | 加宽 0 / 丢弃 0 / **缺失 0** / 多余 72（**全是 `encoder.layers.*`，该丢的**） |
| ★ **Adam 动量** | **共享部分逐位保留**（19/19 相同、0 不同）——`docs/定稿结论.md` §3.3 第 0 条的否决**已过期** |

**判据（预注册）**
窗口 u25/u30；族级配对 n=5（df=4，临界 2.776）+ 可检测效应。
- Δ ≤ −0.020 且 5/5 同向 ⟹ **GNN 有贡献**（图结构必要）⟹ H₁ 拆分假设**支持**
- |Δ| < 0.020 ⟹ **测不出** ⟹ 「GNN 无增益」**方向一致但未测出**（写有界结论）
- Δ ≥ +0.020 ⟹ 去图**更好** ⟹ 当前模型**过参数化**，是大发现

**成本**：5 × 70 min ≈ **6 小时**（一次起，内存 125 GiB）

### E2 · `residual: false` 补到 n=9

**现状**：已跑 `residfalse_s{42..46}`（n=5）：Δ=−0.0105，t=−0.72，**测不出**（可检测 0.0402）。

### E3 · `critic_lr` 剂量扫描

**为什么候选**：`ablation-name-is-not-the-parameter` 指出 `critic_lr` **78/78 全库单调**
（从未扫过）；`docs:12403-12406` 说它不是空旋钮但「信号被压扁 ⟹ 需要的种子数比平时更多」。

**⚠ 但算术不利**（§二十八）：
```
BC 族 Δ_s SD ≈ 0.0137
测出 0.5 点 ⟹ n > 40      测出 1.0 点 ⟹ n > 10
```
今晚 4 条增益类旋钮**全部在 ±1 点内** ⟹ 先验上 `critic_lr` 大概率同量级。
**要测出 1 点需 n≥10**；按 n=15 算约 18 h。

**建议**：除非有**独立理由**相信它效应更大（例如 critic 塌缩那条链），否则**不做**。

### E4 · 真·单智能体 DRL（去中心化执行）—— **需写码**

**现状**：§三十一 实测确认「当前 MAPPO 在架构上**已是单智能体**」——
全局观测 + 一个全局 actor 产出全局匹配 + 全局 critic + `mutual_choice` 空裁决（100%）。

⟹ 若要**名副其实**的「单智能体 vs 多智能体」对照，必须让执行**真去中心化**：
每节点只看自己的局部邻域、独立决策，协调**靠学**。

**代价**：改观测构造 + 采样器 + 训练器，**数天**。
**建议**：**等 E1 的结果**——若 E1 证明「图结构有贡献」，那 CTDE 的价值还需要一条**独立**证据；
若 E1 测不出，说明当前架构的复杂度没换来性能，E4 的价值也随之下降。

**⚠ 不在夜班自主范围**，需用户定。

## 3. ★ 排期原则（**为什么不是"把所有想做的都排上"**）

### 算术决定：**大部分旋钮不值得测**

BC 族 `Δ_s` SD ≈ **0.0137**（n=15 实测）：

| 想测出的 Δ | 所需 n | 机时 |
|---|---|---|
| 0.5 点 | **> 40** | ~47 h |
| 0.75 点 | > 18 | ~21 h |
| 1.0 点 | > 10 | ~12 h |
| 2.0 点 | > 6 | ~7 h |

**今晚 8 条旋钮里，4 条增益类的 Δ 全在 ±1 点内** ⟹ 继续扫同类旋钮**大概率还是"测不出"**。

### ⟹ 三条排期原则

1. **优先"结构调整"而非"超参微调"**：结构改动（去图、去协调）**效应量大**，
   能在 n=5 就测出；超参微调多半在 1 点内，要 n>40。
2. **优先"同时回答多个问题"的**：E1 既补 H₁ 拆分假设、又答模型合理性。
3. **前置勘察优先于起臂**：今晚靠勘察（不花机时）查到两条重要事实——
   `dropout` 会静默丢 46% 权重、`num_layers:0` 的否决已过期。
   **每次动手前先跑预检**，成本几分钟、能省几小时。
