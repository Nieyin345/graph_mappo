## 4. 受控天气与四类链路：300 s 单次接触最终有限密钥释放率

以下是**固定几何的独立链路**、晴夜背景；HAP–GS、SAT–GS、SAT–HAP 均为 90°，SAT–SAT 为 500 km。每条链路连续保持 5 个 60 s 槽，首槽扣除 5 s 捕获时间；信道环境参数由 `tools/short_channel_rate_study.py` 的 `SCENARIOS` 定义，非真实天气记录。数据是最终 300 s block 释放比特数除以 300 s，单位 **kbit/s**，不是全网可同时实现吞吐量。

其中 `broken_cloud` 是 5 槽的一个确定性示例（第 2、4 槽遮挡，3/5 槽可贡献计数），**不是**从 50% 云量推导的精确平均密钥率。完全遮挡时，主基线 LOS gate 让地面链路贡献零有效脉冲，但高空/星间链路仍保持数值不变。

### 条件速率与最终释放率的区别

单独看未遮挡条件下的 `conditional_finite_300_bps`，低中云的云量改变并不会改变条件光学信道；因此 `broken_cloud` 和 `overcast` 的**条件**速率等于 `clear`。这是条件概率定义，不是遮挡没有生效。实际释放率须把站点随机云门控、首槽捕获和完整 block 统计计算进去，如上表。

## 5. 合理性及边界

1. 方向正确：更高 AOD、近地湍流、薄高云对地面链路产生降速；遮挡门控抑制整块密钥；上层链路对地面天气不敏感是**被明确写出的模型假设**。
2. 数值量级：HAP–GS 在当前硬件/高度下为约 0.1–1 Mbit/s；SAT–GS、SAT–HAP、短距 SAT–SAT 为约 kbit/s，量级与先前受控速率报告相容；不能跨设备/波长将其视为实测复现。
3. 本次固定链路的简测没有验证真实轨道随时间改变的接触持续性、端口冲突、路由、网络调度策略或真实 ERA5/CAMS 气象输入；完整 24 小时受控合成天气检查见 `docs/短期信道速率量级验证_20261008.md`。
4. 物理限制保持不变：HAP 有限 Gaussian 束以球面波近似；有界 Beta 为统计闭合；`V_R>=1` 属弱起伏外推域；高海拔 AOD 仍是参考气柱工程代理。
5. 当前没有从受控样本找到需要人工调节统一损耗或改写有限密钥公式的证据；**建议不要再为追求全面物理复杂度而扩展主模型**。论文应把主要贡献放在网络调度及策略比较，并保持对参数敏感性的必要检查。
